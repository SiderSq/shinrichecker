# ★ Shinri Reviews Ranker (DRO Edition)

Профессиональное приложение для автоматического сбора, анализа и ранжирования игроков с платформы **[shinrireviews.com](https://shinrireviews.com)** (сообщество **Danganronpa Online / DRO**).

Программа формирует объективные списки **лучших (Топ-N)** и **худших (Антитоп-N)** игроков на основе среднего рейтинга отзывов сообщества и Байесовского сглаживания, обрабатывает краевые случаи, парсит логи игровых комнат, отображает персонажей DRO и строит инфографику.

---

## 🚀 Быстрый старт на Windows

1. **Веб-интерфейс в браузере (рекомендуется):**  
   Дважды кликните по файлу **`run_web.bat`** (или выполните `python main.py`).  
   В браузере откроется интерактивная панель управления по адресу `http://127.0.0.1:8088`.
2. **Консольный режим (CLI):**  
   Дважды кликните по файлу **`run_cli.bat`** (или выполните `python main.py --cli --input sample_players.txt --top 10`).

## 🌟 Новые возможности и улучшения

### 1. 🌟 Байесовский рейтинг (Bayesian Average)
- **Проблема классического среднего:** Игрок с 1 оценкой 5.0 оказывается на 1 месте выше ветерана с 94 отзывами и средним 4.95, а игрок с 1 оценкой 1.0 оказывается на самом дне антирейтинга.
- **Решение:** Программа рассчитывает взвешенный Байесовский балл:
  $$R_{bayes} = \frac{v \cdot \bar{R} + m \cdot C}{v + m}$$
  где $v$ — количество отзывов игрока, $\bar{R}$ — его средний балл, $C$ — глобальный средний балл по сайту (~4.80), $m$ — порог доверия ($m=5$).
- Доступно переключение между **Байесовским рейтингом** и **Классическим средним баллом** в Web UI и CLI (`--ranking-mode bayesian|classic`).

### 2. 💬 Умный парсер чата и логов лобби Danganronpa Online (DRO)
- Вкладка **«Лог чата DRO»** в веб-интерфейсе и флаг `--chat-log` в CLI:
  Вы можете скопировать произвольный лог матча или чата (например: `[18:40] Player1 вошел в комнату`, `Комната #14: P1, P2, P3...`, `Player4: привет`).
- Парсер автоматически распознает и извлечет никнеймы всех участников комнаты, отфильтрует системные сообщения и сразу построит рейтинг игроков лобби!

### 3. 🎭 Отображение игровых аватарок и спрайтов персонажей DRO
- В базу встроено сопоставление **119 персонажей Danganronpa** (`avatarGameId`: Shuichi, Kokichi, Junko, Chiaki, Nagito, Celestia, Korekiyo и др.).
- В карточках игроков и на инфографике отображаются оригинальные аватарки платформы.

### 4. 🔍 Углубленный анализ отзывов и цитаты сообщества
- При клике на кнопку **«💬 Отзывы»** в карточке игрока открывается окно с детальным анализом:
  - **Верифицированный рейтинг:** Средний балл, рассчитанный *только по отзывам подтвержденных игроков* (`authorVerified: true`).
  - **Наиболее полезный отзыв:** Цитата текста отзыва с максимальным количеством лайков сообщества.
  - **Облако частых слов:** Ключевые слова и характеристики из отзывов.
  - **История никнеймов:** Прошлые имена игрока при смене ника.

### 5. ⚔️ Прямое сравнение игроков (Head-to-Head)
- Выберите чекбоксами от 2 до 4 игроков и нажмите **«⚔️ Сравнить выбранных»**:
  Откроется сравнительная таблица с сопоставлением среднего балла, Байесовского рейтинга, проверенных отзывов и истории ников.

### 6. 📷 Улучшенное OCR-распознавание со скриншотов таблицы счета и лобби
- **Вставка скриншота из буфера обмена (Ctrl+V):** Нажмите `Ctrl+V` в любом месте окна веб-интерфейса, чтобы вставить скопированный скриншот лобби, таблицы счета или чата.
- **Двойной движок распознавания:**
  1. *Нативный Windows Media OCR:* Встроенный в Windows 10/11 аппаратный движок через Python `winrt` — мгновенное распознавание без внешних зависимостей.
  2. *Клиентский Tesseract.js:* Автономное распознавание в браузере с отображением прогресс-бара.
- **Предварительная обработка изображений (PIL):**
  - Преобразование в градации серого (`mode: L`).
  - Высококачественное масштабирование мелких игровых шрифтов (LANCZOS до ширины от 1200px).
  - Усиление контрастности (1.8x) и фильтр повышения резкости (`ImageFilter.SHARPEN`).
- **Интеллектуальное разделение и очистка токенов:**
  - Удаление игрового мусора: пинг (`45ms`, `120 ms`), временные метки (`[18:40:12]`), скобки, разделители таблиц.
  - Детекция и разъединение случайно склеенных OCR слов по базе игроков.
- **Нечеткое сопоставление (Fuzzy Autocorrection):**
  - Автоматическое исправление артефактов OCR (например, `mercyflmver` $\rightarrow$ `mercyflower^-^`, `hunck` $\rightarrow$ `Hunk`) с помощью сопоставления по всей базе 5 414 игроков.
  - Индикация схожести, цветные бейджи и отображение оригинального текста OCR.
- **Консольный режим:** Флаг `--ocr <путь_к_файлу>` для автоматического распознавания скриншотов из терминала.

### 7. ⚖️ Честный балансировщик команд (Fair Matchmaking)
- Разделение участников матча на две максимально равные команды: **Синяя команда (Team Blue)** и **Красная команда (Team Red)**.
- **Алгоритм:** Жадное змейкоподобное распределение (Snake allocation) с последующей глобальной оптимизацией попарными перестановками (**2-opt pairwise swaps**).
- **Показатели честности:**
  - Процент честности матча (*Fairness Index* от 0% до 100%).
  - Минимальная разница средних баллов команд (*Delta* $\le 0.05$).
  - Назначение сильнейших игроков капитанами команд.
  - Удобная кнопка **«📋 Скопировать составы»** с готовым форматированием для отправки в игровой чат или Discord.
- **Консольный режим:** Флаг `--balance-teams`.

### 8. 🛡️ Индикатор надежности и токсичности комнаты (Lobby Safety Meter)
- Оценка стабильности и безопасности игровой комнаты по шкале от 0 до 100:
  - **Высокая надежность (Safe, 80–100):** Зеленый индикатор, опытные игроки с хорошей репутацией.
  - **Умеренный риск (Moderate, 55–79):** Желтый индикатор, присутствуют игроки с рейтингом ниже среднего.
  - **Высокий риск (High Risk, < 55):** Красный индикатор, присутствуют игроки с критически низким рейтингом ($\le 2.2$) — риск троллинга, слива или лива из матча.
- Детализация по каждому участнику с выводом предупреждений.
- **Консольный режим:** Флаг `--lobby-safety`.

### 9. 🖼️ Экспорт в графическую карточку (PNG-инфографика)
- Кнопка **«🖼️ Скачать инфографику (PNG)»** прямо в браузере генерирует стильное темное изображение (1000x650) с Топ-5 лучших и худших игроков, баллами, медалями и аватарками. Идеально для быстрой отправки в Discord и Telegram.

### 11. 🏷️ Клановая аналитика и предупреждение о сговоре (Clan & Teaming Detector)
- Автоматическое распознавание клановых тегов (`[TAG]`, `{TAG}`, `(TAG)`, `|TAG|`, `TAG_`, `^TAG^`).
- Агрегация среднего балла и среднего Elo для каждого клана в комнате.
- Интеллектуальный детектор тиминга: если клан представлен $\ge 3$ игроками в одной комнате, система выдает предупреждение о риске сговора в лобби.
- Бейджи кланов отображаются в таблице рейтинга и в карточках игроков.
- **Консольный режим:** Флаг `--clans`.

### 12. 🏆 Генератор турнирных сеток (DRO Tournament Bracket)
- Посев игроков по Байесовскому рейтингу:
  - **Single Elimination (Плей-офф на выбывание):** Классическая сетка (1 vs N, 2 vs N-1), расчет шанса победы в каждом матче на базе Elo, подсветка фаворита.
  - **Round Robin (Групповой этап):** Snake-распределение по 4-местным группам (Группа A, B, C...) со сбалансированной силой и расписанием всех очных встреч.
  - Кнопка **«📋 Скопировать расписание матчей»** для быстрой публикации турнира в Discord/Telegram.
- **Консольный режим:** Флаг `--tournament {single_elimination,round_robin}`.

### 13. ⚡ Соревновательный Elo и прогноз исхода матчей
- Маппинг оценок Shinri (1.0–5.0) в соревновательные очки Elo (800–2200):
  $$Elo = 800 + (R - 1.0) \times 350$$
- Логистический расчет вероятности победы команды A против B:
  $$P(A) = \frac{1}{1 + 10^{(Elo_B - Elo_A)/400}}$$
- Прогноз победы отображается в балансировщике команд, турнирной сетке и карточке игрока.

### 14. 🎴 Коллекционные карточки игроков (Collectible Player Cards)
- Назначение уникального титула-архетипа по стилю игры и репутации:
  - *«Абсолютный Детектив»* (рейтинг $\ge 4.90$, $\ge 20$ отзывов)
  - *«Мастер Дедукции»* (рейтинг $\ge 4.50$)
  - *«Опытный Следователь»* (рейтинг $\ge 3.80$)
  - *«Рядовой Ученик»* (рейтинг $\ge 2.80$)
  - *«Сомнительный Свидетель»* (рейтинг $\ge 2.20$)
  - *«Главный Подозреваемый»* (рейтинг $< 2.20$)
  - *«Скрытый Талант»* (новичок без истории отзывов)
- Анализ тональности отзывов (Sentiment Analysis) с разметкой плюсов и замечаний.
- Генерация и скачивание стильной 460x640 визитки игрока в формате PNG.

### 15. ⚡ Высокопроизводительные оптимизации
- **Ускорение нечеткого поиска в ~15 раз:** Быстрый путь $O(1)$ для точных совпадений, предварительно кэшированный индекс нижнего регистра, математическое отсечение кандидатов по разнице длин строк (`max_len_diff = int(len * (1 - cutoff) + 2)`).
- **Предварительная очистка клановых тегов:** Если ник вида `[DR] Hunk` не найден целиком, префикс отсекается до вызова тяжелого fuzzy matcher.
- **Умная дельта-синхронизация (Smart Delta Sync):** Метод `refresh_delta()` сверяет записи базы данных по хэшам и возвращает детальную статистику добавленных и измененных профилей (`+N новых, ~M обновлено`).
- **Debounce поиска (100 мс):** Мгновенная плавная фильтрация списков без лагов интерфейса.

## 💻 Примеры команд CLI

```powershell
# 1. Анализ игроков с проверкой кланов, балансом команд, оценкой лобби и турнирной сеткой
python main.py --cli -p "Hunk, mercyflower^-^, Pateti, Bun|dimebag" --balance-teams --lobby-safety --clans --tournament single_elimination

# 2. Групповой этап турнира (Round Robin)
python main.py --cli --input sample_players.txt --tournament round_robin

# 3. Полный анализ со скриншота через OCR с балансировкой команд и оценкой безопасности
python main.py --cli --ocr ocr_test.png --balance-teams --lobby-safety --clans

# 4. Расчет рейтинга из файла с балансировкой команд и индикатором безопасности
python main.py --cli --input sample_players.txt --top 10 --balance-teams --lobby-safety

# 5. Расчет по классическому среднему баллу
python main.py --cli --input sample_players.txt --ranking-mode classic --top 10

# 6. Парсинг сырого лога матча / лобби DRO
python main.py --cli --input sample_chat.txt --chat-log --top 5

# 7. Экспорт результатов во все форматы (CSV, JSON, Markdown)
python main.py --cli --input sample_players.txt --top 5 --export-csv results.csv --export-json results.json --export-md results.md

# 8. Ручной режим для омонимов (вывод кандидатов без автовыбора)
python main.py --cli --input sample_players.txt --manual-ambiguous

# 9. Оффлайн-режим из локального кэша
python main.py --cli --input sample_players.txt --offline
```
